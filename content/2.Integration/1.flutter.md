# Dynalink Flutter Plugin

The **Dynalink Flutter plugin** simplifies deep link handling, install attribution, and campaign tracking in Flutter apps. It automatically captures ad-network click IDs (gclid, fbclid, ttclid, and more) during the pre-install browser session and exposes them after the app is opened.

## Installation

### Step 1: Add Dependency

```yaml
dependencies:
  dynalink_flutter: ^0.0.13
```

```bash
flutter pub get
```

---

### Step 2: Configure Platforms

#### Android

Update `AndroidManifest.xml`:

```xml
<intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="dynalink-{projectId}" android:host="dynalink.app" />
</intent-filter>

<intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="https" android:host="{projectPrefix}.dynalink.app" />
</intent-filter>
```

Add **Asset Links** in the Admin Panel under Project → Settings.  
See [Android App Links docs](https://developer.android.com/training/app-links/verify-android-applinks#web-assoc).

> **What `android:autoVerify="true"` changes.** Once Android has verified your
> `assetlinks.json`, `https://{projectPrefix}.dynalink.app/{code}` opens the app
> **directly** — the browser and the DynaLink loading page are skipped. The app then
> receives the *short* URL, not the destination: the SDK resolves it through
> `GET /api/links/{code}` and emits it as `DynalinkEvent.actualUrl`, and reports the
> click itself via `POST /api/links/{code}/click` so your statistics stay accurate.
>
> Always navigate with `event.actualUrl` from the stream — never by parsing the
> incoming URL path. And leave Flutter's own deep linking off
> (`<meta-data android:name="flutter_deeplinking_enabled" android:value="false" />`)
> so your router does not also try to navigate to `/{code}`.

#### iOS

Update `ios/Runner/Info.plist`:

```xml
<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLName</key>
    <string>{bundleId}</string>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>dynalink-{projectId}</string>
    </array>
  </dict>
</array>

<key>NSUserActivityTypes</key>
<array>
  <string>NSUserActivityTypeBrowsingWeb</string>
</array>

<key>LSApplicationQueriesSchemes</key>
<array>
  <string>dynalink-{projectId}</string>
</array>

<key>CFBundleAssociatedDomains</key>
<array>
  <string>applinks:{projectPrefix}.dynalink.app</string>
</array>

<key>FlutterDeepLinkingEnabled</key>
<false/>
```

Add the **Apple App Site Association** file in the Admin Panel under Project → Settings.  
See [Apple Associated Domains docs](https://developer.apple.com/documentation/xcode/supporting-associated-domains).

### Step 3: Initialize the Plugin

```dart
import 'package:dynalink_flutter/dynalink_flutter.dart';
import 'package:flutter/material.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  await Dynalink.initialize(
    publicKey: 'YOUR_PROJECT_KEY',
    projectId: 'YOUR_PROJECT_ID',
    // Optional — hosts other than {projectPrefix}.dynalink.app that serve your
    // links. Declaring them here makes link handling work on the very first link;
    // otherwise the SDK resolves them from the API the first time it sees an
    // unknown host.
    customDomains: const ['links.yourdomain.com'],
  );

  runApp(const MyApp());
}
```

## Handling Deep Link Events

Every time a DynaLink is processed — whether from an incoming deep link, an install referrer, or a clipboard match — the `dynamicLinkStream` emits a `DynalinkEvent`.

```dart
Dynalink.instance.dynamicLinkStream.listen((DynalinkEvent event) {
  // Navigate to the resolved URL
  print('Navigate to: ${event.actualUrl}');

  // Campaign / UTM context
  if (event.hasCampaign) {
    print('Campaign: ${event.campaignName} (id: ${event.campaignId})');
    print('UTM: ${event.utmSource} / ${event.utmMedium} / ${event.utmCampaign}');
  }

  // Ad-network click IDs — forward to your measurement SDKs
  if (event.hasClickIds) {
    if (event.gclid != null)   forwardToGoogleAds(event.gclid!);
    if (event.fbclid != null)  forwardToFacebookCAPI(event.fbclid!, event.fbclidCapturedAt);
    if (event.ttclid != null)  forwardToTikTokEvents(event.ttclid!);
    if (event.twclid != null)  forwardToXAds(event.twclid!);
    if (event.liFatId != null) forwardToLinkedIn(event.liFatId!);
  }
});
```

### `DynalinkEvent` Fields

| Field               | Type       | Description                                                     |
|---------------------|------------|-----------------------------------------------------------------|
| `actualUrl`         | `String`   | Resolved destination URL to navigate to                         |
| `campaignId`        | `int?`     | Campaign ID associated with this link                           |
| `campaignName`      | `String?`  | Campaign display name                                           |
| `utmSource`         | `String?`  | UTM source                                                      |
| `utmMedium`         | `String?`  | UTM medium                                                      |
| `utmCampaign`       | `String?`  | UTM campaign slug                                               |
| `utmTerm`           | `String?`  | UTM term                                                        |
| `utmContent`        | `String?`  | UTM content                                                     |
| `gclid`             | `String?`  | Google Ads click ID                                             |
| `gbraid`            | `String?`  | Google Ads enhanced click ID (iOS 14.5+)                        |
| `fbclid`            | `String?`  | Meta (Facebook/Instagram) click ID                              |
| `fbclidCapturedAt`  | `DateTime?`| When the fbclid was first captured in the browser               |
| `ttclid`            | `String?`  | TikTok click ID                                                 |
| `twclid`            | `String?`  | X (Twitter) click ID                                            |
| `liFatId`           | `String?`  | LinkedIn first-party ad tracking ID                             |
| `attributedAt`      | `DateTime?`| When the backend confirmed the install match                    |

## Persisted Attribution Getters

If you need click IDs outside of the stream (e.g. on a screen that loads after the event fires), use the persisted getters. Values are written to `SharedPreferences` automatically when an attribution event is received.

```dart
final gclid   = await Dynalink.instance.getLastGclid();
final fbclid  = await Dynalink.instance.getLastFbclid();
final ttclid  = await Dynalink.instance.getLastTtclid();
final twclid  = await Dynalink.instance.getLastTwclid();
final gbraid  = await Dynalink.instance.getLastGbraid();
final liFatId = await Dynalink.instance.getLastLiFatId();

final campaignId = await Dynalink.instance.getLastCampaignId();
```

## Attribution API

Query the attribution API directly for on-demand lookups, or to re-check after an earlier call.

```dart
// By device fingerprint
final result = await Dynalink.instance.getAttributionByFingerprint(fingerprint);

// By DynaLink short code
final result = await Dynalink.instance.getAttributionByCode('SUMR99');

if (result != null && result.matched) {
  print('Attributed at: ${result.attributedAt}');
  print('gclid: ${result.gclid}');
  print('fbclid: ${result.fbclid}');
}
```

### `AttributionResult` Fields

| Field               | Type       | Description                                              |
|---------------------|------------|----------------------------------------------------------|
| `matched`           | `bool`     | Whether a confirmed attribution was found                |
| `dynaCode`          | `String?`  | The short code of the matched link                       |
| `gclid`             | `String?`  | Google Ads click ID                                      |
| `gbraid`            | `String?`  | Google Ads enhanced click ID                             |
| `fbclid`            | `String?`  | Meta click ID                                            |
| `fbclidCapturedAt`  | `DateTime?`| When fbclid was captured                                 |
| `ttclid`            | `String?`  | TikTok click ID                                          |
| `twclid`            | `String?`  | X (Twitter) click ID                                     |
| `liFatId`           | `String?`  | LinkedIn first-party ID                                  |
| `campaignId`        | `int?`     | Associated campaign ID                                   |
| `campaignName`      | `String?`  | Campaign display name                                    |
| `utmSource`         | `String?`  | UTM source                                               |
| `utmMedium`         | `String?`  | UTM medium                                               |
| `utmCampaign`       | `String?`  | UTM campaign slug                                        |
| `utmTerm`           | `String?`  | UTM term                                                 |
| `utmContent`        | `String?`  | UTM content                                              |

## Creating Links

```dart
final shortenedUrl = await Dynalink.instance.createShortenedLink(
  CreateDynalinkForm(
    url: 'https://yourapp.io?screen=offer&id=99',
    iosUrl: 'https://apps.apple.com/app/id123456789',
    androidUrl: 'https://play.google.com/store/apps/details?id=com.yourapp',
    socialTitle: 'Check this out',
    socialDescription: 'Exclusive summer deal — 40% off',
    socialImage: 'https://yourapp.io/og-summer.jpg',
    fallbackUrl: 'https://yourapp.io',
    isDeepLink: true,
    campaignId: 4,
  ),
);

print('Share this: $shortenedUrl');
```

## Campaign Management

```dart
// List campaigns (optionally filter by status)
final campaigns = await Dynalink.instance.getCampaigns(status: 'active');

// Get a single campaign
final campaign = await Dynalink.instance.getCampaign(4);

// Create a campaign
final newCampaign = await Dynalink.instance.createCampaign(
  CreateCampaignForm(
    name: 'Summer 2026',
    status: 'active',
    utmSource: 'google',
    utmMedium: 'cpc',
    utmCampaign: 'summer_2026',
  ),
);

// Get campaign stats (last 30 days by default)
final stats = await Dynalink.instance.getCampaignStats(4, days: 7);
print('Total clicks: ${stats?.totalClicks}');
```

## How Attribution Works

1. **Click** — A user clicks a DynaLink. The Dynalink fingerprint page captures any ad-network click IDs present in the URL (`gclid`, `fbclid`, etc.) and stores them server-side against the device fingerprint (`{IP}-{OS}-{Version}-{Resolution}`).

2. **Redirect** — The page redirects to the App Store (iOS) or Play Store (Android). On Android, the original DynaLink URL is passed as the install referrer.

3. **Install & Open** — The user installs and opens the app. The SDK runs the attribution flow:
   - **Android**: reads the install referrer URL, parses the code, fetches click IDs from the attribution API.
   - **iOS (clipboard)**: if the DynaLink URL is in the clipboard, it is processed the same way.
   - **iOS (fingerprint)**: if no clipboard URL is found, the SDK re-generates the device fingerprint, finds the pending link, marks it as confirmed, then fetches click IDs from the attribution API.

4. **Event** — A `DynalinkEvent` is emitted on `dynamicLinkStream` with the full attribution payload, including click IDs. Values are also saved to `SharedPreferences` for later retrieval.

## Testing

- **Android**: use the [Play Store Install Referrer tester](https://medium.com/@madicdjordje/how-to-test-the-play-store-install-referrer-api-78a63d59945b) to simulate an install referrer.
- **iOS**: paste a DynaLink URL into the device clipboard, then launch the app from Xcode to trigger the clipboard attribution flow.
- **Attribution API**: call `getAttributionByCode('YOUR_CODE')` after processing a link to verify click IDs are returned correctly.
