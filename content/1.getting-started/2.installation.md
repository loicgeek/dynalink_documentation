# Dynalink API

The Dynalink API allows you to programmatically create, manage, and use smart links across platforms, supporting deep links, store redirects, web fallbacks, and social media previews.

---

## Authentication

Every request requires a **Project Key** via the `x-project-key` header.

```http
x-project-key: YOUR_PROJECT_KEY
```

### Obtaining Project Key
1. Login to [Dynalink Admin](https://admin.dynalink.app)  
2. Create a new project  
3. Copy the generated project key  

### Security Best Practices
- Store your key securely  
- Never expose your key in client-side code  
- Use environment variables for safe key management  

### Example API Request
```javascript
fetch('https://dynalink.app/api/endpoint', {
  headers: {
    'x-project-key': 'your_project_key_here',
    'Content-Type': 'application/json'
  }
})
```

---

## Creating a Dynalink

Dynalink enables you to create smart links for deep linking, fallback navigation, and social media previews.

### Endpoint

```http
POST https://dynalink.app/api/links
```

### Request Body Parameters

| Parameter              | Type    | Required | Description                                                   |
|------------------------|---------|----------|---------------------------------------------------------------|
| `actual_url`           | string  | Yes      | The original destination URL                                  |
| `ios_url`              | string  | No       | Direct link to iOS App Store                                  |
| `android_url`          | string  | No       | Direct link to Google Play Store                              |
| `fallback_url`         | string  | No       | Alternative URL if linking fails                              |
| `is_deeplink`          | boolean | No       | Whether the link is a deep link                               |
| `should_open_store`    | boolean | No       | Whether to open the store if the app is not installed         |
| `social_title`         | string  | No       | Title for social media sharing                                |
| `social_description`   | string  | No       | Description for social media sharing                          |
| `social_image`         | string  | No       | Image URL for social media sharing                            |
| `ios_bundle_id`        | string  | No       | iOS Bundle ID (auto-resolves App Store link if provided)      |
| `android_package_name` | string  | No       | Android package name (auto-resolves Play Store link if given) |

## Link Types

### 1. Standard Web Link
- Users always land on the web page.
```json
{
  "actual_url": "https://neero.io",
  "fallback_url": "https://neero.io"
}
```

### 2. Deep Link Only
- Opens the app if installed.
- Falls back to web if app is not installed.
```json
{
  "actual_url": "https://neero.io?appId=34&type=pendingPayment",
  "is_deeplink": true,
  "should_open_store": false,
  "fallback_url": "https://neero.io"
}
```

### 3. Deep Link with Store Fallback
- Opens app if installed.
- Opens App Store / Play Store if app not installed.
```json
{
  "actual_url": "https://neero.io?appId=34&type=pendingPayment",
  "is_deeplink": true,
  "should_open_store": true,
  "ios_bundle_id": "com.dynalink.app",
  "android_package_name": "com.dynalink.app",
  "fallback_url": "https://neero.io"
}
```

### 4. App Store / Play Store Only
- Direct users to the App Store or Play Store.
```json
{
  "ios_url": "https://apps.apple.com/fr/app/neero-paie-transfert-recharge/id6449452176",
  "android_url": "https://play.google.com/store/apps/details?id=com.neero.app",
  "fallback_url": "https://neero.io"
}
```

### 5. Social Preview Enabled
- Adds metadata for rich link previews on social media.
```json
{
  "actual_url": "https://neero.io?appId=34&type=pendingPayment",
  "social_title": "Pay, Transfer & Recharge",
  "social_description": "Manage your finances seamlessly with Neero",
  "social_image": "https://plus.unsplash.com/premium_photo-1664910125402-7972b1e12b79",
  "fallback_url": "https://neero.io"
}
```

### Example Request

```bash
curl -X POST https://dynalink.app/api/links \
-H "Content-Type: application/json" \
-H "x-project-key: YOUR_PROJECT_KEY" \
-d '{
  "actual_url":"https://neero.io?appId=34&type=pendingPayment",
  "is_deeplink": true,
  "should_open_store": true,
  "fallback_url":"https://neero.io",
  "social_title":"Pay, Transfer & Recharge",
  "social_description":"Manage your finances seamlessly with Neero",
  "social_image":"https://plus.unsplash.com/premium_photo-1664910125402-7972b1e12b79",
  "ios_bundle_id":"com.dynalink.app",
  "android_package_name":"com.dynalink.app"
}'
```

## Notes
- Ensure URLs are valid and accessible  
- Provide social metadata for rich link previews  
- Always include a `fallback_url` for the best user experience  
- Verify `ios_bundle_id` and `android_package_name` for deep links  
- Keep `x-project-key` secure and server-side when possible
