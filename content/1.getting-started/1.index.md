# Introduction

**Dynalink** is a powerful platform for managing **deep links** and **dynamic links** across multiple platforms and frameworks.  
It allows developers to create smart links that improve user experience, app navigation, and social media link previews.

## Key Features

- **Deep Link Handling**: Capture and process incoming deep links to navigate users to specific screens.  
- **Dynamic Link Creation**: Generate flexible links for cross-platform sharing.  
- **Shortened URLs**: Create compact, shareable links for marketing campaigns.  
- **Custom Parameters**: Pass extra data in links for personalized user experiences.  
- **Cross-Platform SDKs**: Works with Flutter, iOS, Android, and Web.  
- **Analytics & Tracking** *(coming soon)*: Measure link usage and campaign performance.  

## Use Cases

- **Content Sharing**: Share app-specific content via dynamic or shortened links.  
- **Referrals & Promotions**: Implement invite systems and track campaigns.  
- **Onboarding Flows**: Guide users from install to specific in-app screens.  
- **Cross-Platform Campaigns**: One link works for both iOS and Android with automatic fallback.
